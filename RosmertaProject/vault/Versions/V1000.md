# V1.0.0.0 — Building Blocks

First release. Mainly stands up the building blocks of the system.

**Release summary:** getting the core ingest → store → analyse → visualise pipeline in place.

## Components
- `mm`, `bl` (per `metadata.json` deployment manifest)

## Services
- PostgreSQL · Interactive Brokers (`ib-insync`) · SEC EDGAR

## What shipped
- IB hourly price + portfolio ingestion; SEC EDGAR fundamentals & dividends (with IB fallback).
- PostgreSQL schema (`stocks`, `price_hourly`, `dividends`, `fundamentals`, watchlists, `fetch_log`).
- `Asset` / `Market` analysis layer and the `@register` indicator registry (`sma`, `ema`, `rsi`, `bollinger`, `obv`, `vwap`, `days_offset_gain`).
- Dash dashboard and the DB-free pytest suite.
